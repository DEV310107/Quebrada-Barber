📄 Política de Privacidade, Termos de Uso e Uso de Dados

Este documento reúne a Política de Privacidade, Termos de Uso e informações sobre tratamento de dados do site.

🔵 1. Política de Privacidade

Este site coleta e utiliza dados pessoais de usuários com o objetivo de fornecer autenticação, melhorar a experiência e permitir o funcionamento dos serviços.

📌 Quais dados são coletados

  • E-mail do usuário
  • Informações de login (via Firebase Authentication)
  • Dados de navegação básicos (como IP e dispositivo, quando aplicável)

📌 Como os dados são utilizados

Os dados coletados são utilizados para:

  • Criar e gerenciar contas de usuário
  • Permitir login e autenticação no sistema
  • Melhorar a segurança do site
  • Oferecer funcionalidades personalizadas

📌 Armazenamento

Os dados são armazenados de forma segura utilizando serviços como Firebase, fornecido pelo Google.

📌 Compartilhamento de dados

Não vendemos nem compartilhamos dados pessoais com terceiros, exceto quando necessário para funcionamento do serviço (ex: Firebase).

📌 Direitos do usuário (LGPD)

O usuário pode:

  • Solicitar acesso aos seus dados
  • Solicitar correção ou exclusão de dados
  • Revogar consentimento a qualquer momento

📜 2. Termos de Uso

Ao utilizar este site, você concorda com os seguintes termos:

📌 Uso do serviço

  • O usuário se compromete a fornecer informações verdadeiras no cadastro
  • É proibido tentar invadir, hackear ou prejudicar o sistema

📌 Conta do usuário

  • O usuário é responsável por manter a segurança da sua conta
  • Não compartilhe sua senha com terceiros

📌 Suspensão de conta

Podemos suspender ou remover contas que violem estes termos ou utilizem o sistema de forma indevida.

📌 Alterações

Estes termos podem ser atualizados a qualquer momento sem aviso prévio.

🔐 3. Uso de Dados (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018):

📌 Finalidade

Os dados são coletados exclusivamente para funcionamento do sistema de autenticação e serviços do site.

📌 Consentimento

Ao usar o site, o usuário concorda com a coleta e uso de seus dados conforme descrito neste documento.

📌 Segurança

Adotamos medidas técnicas para proteger os dados contra acesso não autorizado, perda ou vazamento.

📌 Contato

Caso o usuário queira solicitar exclusão ou informações sobre seus dados, deve entrar em contato pelo suporte do site.

✅ Observação final

Este documento pode ser atualizado conforme o crescimento do site e adição de novas funcionalidades.
